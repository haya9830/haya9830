## Projects

### 🌾 Fuel Apply

**農作業の記録を、スマートフォンから。**

農作業用機械の稼働時間・給油量を入力し、OneDrive上のExcelに記録するアプリのMVPです。
農業用燃料の免税申請に必要な記録を、スマートフォンから入力できるようにすることを目指しています。

`TypeScript` `React Native` `Expo` `Microsoft Graph`

[Code & README →](https://github.com/haya9830/fuel_apply)
