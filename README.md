機械系での学習と農業の現場経験を土台に、ソフトウェアづくりに取り組んでいます。
農業・ロボット・作業機械が好きで、現在はWebアプリ開発やチーム開発を通じて学んでいます。

- 米国で大規模農業・経営・マーケティングを学習

## 開発に取り組んでいるもの

### RecTime — 学校行事の運営を支えるチーム開発

Webアプリ [recwatch](https://github.com/HalNagoyaRecTime/recwatch) と、バックエンド [rectime-api](https://github.com/HalNagoyaRecTime/rectime-api) の開発に参加しています。

- 参加者選択でのクラス表示・検索の改善
- 停止中の学生を参加者候補から除外する対応
- 行事スケジュールを登録するSQLやデータ整理用マイグレーションの作成
- 変更に合わせたテストの追加・修正

使用技術：TypeScript / React / Hono / Cloudflare Workers・D1 / Vitest

実装例：[クラス表示の改善](https://github.com/HalNagoyaRecTime/recwatch/pull/409) · [参加者候補の改善](https://github.com/HalNagoyaRecTime/recwatch/pull/410) · [スケジュール登録](https://github.com/HalNagoyaRecTime/rectime-api/pull/560)

### Fuel Apply — 農作業の記録をスマートフォンから

農作業用機械の稼働時間・給油量を入力し、Microsoft Graph経由でOneDrive上のExcelに記録するアプリのMVPです。
農業用燃料の免税申請に必要な記録を、スマートフォンから入力できるようにすることを目指しています。

使用技術：TypeScript / React Native / Expo / Microsoft Graph

[リポジトリを見る](https://github.com/haya9830/fuel_apply)

### Aptus — PCパーツ売買サービスの操作プロトタイプ

PCパーツの互換性確認と個人間売買を想定した、画面操作を確認するためのプロトタイプです。
会員登録・ログイン、出品、カート、モック購入などの画面を用意しています。

[リポジトリを見る](https://github.com/haya9830/aptus-mvp-prototype-ia12a203-10)
